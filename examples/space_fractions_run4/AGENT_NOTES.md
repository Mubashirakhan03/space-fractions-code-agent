# AGENT_NOTES.md — agent memory

Space Fractions is a single-user Windows desktop (Tkinter) educational fractions game. Logical components from the web spec map to in-process packages: game/ (Game + state machine), questions/ (Question + answer checking via fractions.Fraction + repository), users/ (User), admin/ (Admin + passcode gate). Domain logic is pure Python (no Tkinter) and testable headless; UI layer calls it. Round = 10 mixed fraction questions (choice + typed). State machine Playing ⇄ Paused → GameOver; invalid transitions raise ValueError. Persistence via SQLite (scores table) with schema.sql; seed questions in data/questions.json (20+ across equivalent/compare/add-subtract/simplify). UI: Canvas space background (#0B1736) with stars/planets drawn on <Configure>, big fonts (title 36+, question 30, buttons 20+), bright accents on dark panels, progress bar + score always visible, pause overlay, end scene with stars + confetti. Answers checked with Fraction so 2/4 == 1/2. Admin default passcode "admin".
