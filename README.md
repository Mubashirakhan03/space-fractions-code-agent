# Space Fractions Code Agent

A simplified, Claude-Code-style **code agent** (Windows desktop app) that reads an architecture
document and UML views, and uses **DeepSeek `deepseek-v4-pro`** (official API) to generate a complete
**Space Fractions** desktop game (Tkinter) — source code, tests, README and design decisions.

> 🚧 Work in progress — Task 1 evaluation, Intelligent Software Engineering group.
